## Chip-8 emulator in Rust

This small project is my Rust learning playground. Hopefully, by the end of this I'd be able to understand and use the basic concepts of the language. No code will be AI-generated, otherwise there's no much point in learning, I believe. I might use AI for explanations or information search but not more than that.

### Features

- [ ] Chip-8 emulator
- [ ] Quirk toggles
- [ ] TUI
- [ ] Debug info in TUI (maybe?)

### Usage

```bash
rusted-chip <filename> --shift-in-place --jump-with-offset --increment-index-memory
```
