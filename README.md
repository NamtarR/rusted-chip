## Chip-8 emulator in Rust

This small project is my Rust learning playground. Hopefully, by the end of this I'd be able to understand and use the basic concepts of the language.

### Features

- [ ] Chip-8 emulator
- [ ] Quirk toggles
- [ ] TUI
- [ ] Debug info in TUI (maybe?)

### Usage

```bash
rusted-chip <filename> --shift-in-place --jump-with-offset --increment-index-memory
```
